Connecting…
It works without any account, through a free public Solana node; each wallet is checked about every 25 seconds. Optional: for faster updates, paste a free key from dashboard.helius.dev. It's saved only in this browser.
Live covers buys and sells by every account with a wallet (all 92 in the standard list). pump.fun trades are labelled PUMP; everything else shows the DEX it went through, because Axiom and GMGN both trade through the same on-chain pools. X posts and callouts need the paid X API, so they're off. Token names and market caps come from DexScreener. Works when opened as a file or from a website (like GitHub Pages); the claude.ai preview blocks outside connections.
